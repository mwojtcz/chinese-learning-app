# Product Roadmap

This roadmap tracks work that is not yet complete. The Polish A1–C2 course is currently a 24-module learning plan with examples, short exercises, and open-ended tasks; it is not yet a complete graded textbook.

## Learning content

- [ ] Expand Polish noun, adjective, pronoun, and verb paradigms beyond the currently curated sample words.
- [ ] Add more Polish exercises with accepted answers, explanations, and level-specific review.
- [ ] Add Chinese example sentences, listening practice, and pronunciation audio.
- [ ] Add Polish audio and more guided practice for cases, aspect, and number agreement.

## Study tools

- [ ] Add spaced repetition and scheduled review sessions.
- [ ] Add learning-history and retention statistics.
- [ ] Add vocabulary-list import, export, and backup.
- [ ] Add optional study reminders.

## Quality

- [ ] Add broader widget tests for flashcard direction, update prompts, and narrow-screen layouts.
- [ ] Improve accessibility, keyboard navigation, and reduced-motion support.
- [ ] Review ambiguous vocabulary glosses and keep source attribution current.
