# Vocabulary data attribution

This application includes adapted HSK 2025 vocabulary lists from
[krmanik/HSK-3.0](https://github.com/krmanik/HSK-3.0), pinned to commit
`182692ce5a11bc30bdc771835d2f0f27491c25de`. The repository's `License.md`
identifies its HSK word lists as CC BY-SA 4.0. The bundled lists are adapted
by joining dictionary metadata and may contain app-specific identifiers for
homographs.

Traditional characters, pinyin, and English glosses are joined from
[CC-CEDICT](https://github.com/krmanik/cedict-json), pinned to commit
`63c2569948629323b515833930fdd10f285401b6`, also identified as CC BY-SA 4.0.
The data builder is `assets/data/scripts/build_hsk_2025_data.py`.

The source repositories and their license notices are provided alongside
these data. Attribution and share-alike terms apply to the derived vocabulary
data; the application's MIT code license does not replace them.
